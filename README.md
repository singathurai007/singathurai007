## 🚀 Featured Projects

### 1. Automated Infrastructure & Application Deployment Pipeline
`Jenkins` `GitHub` `Terraform` `AWS EC2` `Apache`

```text
GitHub → Jenkins → Terraform → AWS EC2 → SSH / SCP → Apache → Application Deployment
```

- Integrated GitHub with Jenkins to trigger the pipeline on every push.
- Provisioned AWS infrastructure as code with Terraform, running `init → validate → plan → apply`.
- Added a **manual approval gate** before infrastructure deployment.
- Automated application delivery to Ubuntu EC2 over **SSH / SCP** and restarted Apache after each deployment.

### 2. Automated CI/CD Pipeline using Jenkins & GitHub
`GitHub Webhooks` `Jenkins` `AWS EC2`

```text
Developer → GitHub → Webhook → Jenkins → Build → Test → Deploy → AWS EC2
```

- Configured **GitHub webhooks** so Jenkins builds automatically after every code push.
- Implemented separate **build, test and deployment** stages.
- Reduced manual deployment effort and shortened release lead time.

### 3. AWS EC2 Monitoring & Alerting
`CloudWatch` `SNS` `EC2`

```text
AWS EC2 → CloudWatch → CPU Alarm → SNS → Email Alert
```

- Monitored EC2 instance health and CPU utilisation.
- Configured **CloudWatch alarms** with **Amazon SNS** email notifications.
- Improved infrastructure issue awareness and response time.
